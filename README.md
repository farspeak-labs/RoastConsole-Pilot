# RoastConsole Pilot

**Live roast logging and control for coffee roasters — on your Mac and (soon) Windows.**

RoastConsole Pilot connects to your roaster, charts bean and environment temperature in real time, marks your milestones, and syncs finished roasts to RoastConsole Cloud. This repository hosts the **downloads and release notes**. The application source is private.

**→ [RoastConsole Pilot on the Mac App Store](https://apps.apple.com/app/id6779781062)**

If Windows shows a blue "Windows protected your PC" dialog, click **More info → Run anyway**. This disappears as the signed publisher reputation establishes.

## What it does

- **Live roast graph** — bean temp, environment temp, and rate-of-rise as the roast runs.
- **Milestone marking** — charge, turning point, first/second crack, drop, with keyboard shortcuts.
- **Broad roaster support** — Kaleido, Aillio, Mill City / Modbus, Loring, IKAWA, TC4/Artisan-compatible boards, and more.
- **AUTO reference-follow** — drive a roast against a saved profile with a deterministic control loop.
- **Cloud sync** — finished roasts and curves land in RoastConsole Cloud.
